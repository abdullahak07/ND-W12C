# COMP6013 Week 12 — Secure Systems Lab

Interactive teaching site for **Lecture 12: Secure System Design and Ethical Responsibilities**.

## Design

The visual design is deliberately modern and non-retro. The **game mechanics and sound feedback** borrow from simple 8-bit arcade ideas — score, lives, waves, timers, XP and short synthesized sound effects — without turning the lecture into an 8-bit visual theme.

## Lecture flow

- CIA Triad
- Defense in Depth
- Threat Modeling
- Equifax breach (2017)
- Facebook–Cambridge Analytica (2018)
- Data privacy
- Security vs usability
- AI and bias
- Responsibility and accountability
- Final review

## Interactive missions

1. **CIA Defender** — timed arcade classification game with lives, score and attack waves.
2. **Layer Stack** — buy defense layers with a limited budget and survive attack waves.
3. **Threat Model Builder** — build Asset → Threat → Vulnerability → Control in context.
4. **Patch Race** — timed server-patching game inspired by the Equifax case.
5. **Consent Check** — make ethical privacy choices while preserving user trust.
6. **Design the Login** — balance security strength against user friction.
7. **Fairness Audit** — identify AI training and evaluation setups that create bias risk.
8. **Accountability Court** — make defensible ethical judgments across developer and organisational responsibility.
9. **Final Challenge** — ten questions with immediate feedback and accumulated Lab XP.

## Sound

All sounds are generated locally in the browser with the Web Audio API. No audio files, external libraries or trackers are required. Sound can be switched off from the header.
